# حواس — ماجراجویی‌های ذهنی

مجموعهٔ هفت بازی فارسی بر اساس پروپوزال، برای اجرا در مرورگر موبایل و کامپیوتر. همهٔ بازی‌ها شامل انتخاب سه سطح، پنج تمرین آموزشی، بازی اصلی، توقف و ادامه، نتیجه و بازی مجدد هستند.

## اجرای محلی

Node.js نسخهٔ ۲۲ یا جدیدتر لازم است. اجرای خود بازی هیچ وابستگی نصبی ندارد:

```sh
cd /home/darklord/Desktop/Ngame/havaas
npm start
```

نشانی اجرا: **http://localhost:4173**. برای اجرای گوشی روی همان شبکه، نشانی IP کامپیوتر را با پورت ۴۱۷۳ باز کنید. برای بازکردن بازی از سرور استفاده کنید؛ بازکردن مستقیم `index.html` با `file://` مناسب ماژول‌های JavaScript نیست.

```sh
npm ci
npm test
npm run build
node scripts/serve.mjs --dist
```

`npm ci` فقط برای نصب ابزار آزمون DOM لازم است. خروجی `dist/` روی هر میزبان فایل ایستا قابل انتشار است. بازی در زمان اجرا به کتابخانه، فونت یا سرویس خارجی درخواست نمی‌زند.

## بازی‌ها و تنظیمات

- **شکار هدفمند:** پنج مجموعهٔ ستاره، شکل، ماهی، پروانه و پرنده؛ انتخاب محرک دارای شکل، رنگ و علامت هدف.
- **کشتی نوح:** جمع‌آوری آب، خوراک، کمک‌های اولیه، جلیقهٔ نجات، چراغ‌قوه و قطب‌نما بر اساس سطح؛ تکمیل کوله و سوارشدن پیش از پایان زمان.
- **سفینهٔ فضایی:** جمع‌آوری اکسیژن، لباس فضایی، سوخت، کلاه فضایی، خوراک و نقشه بر اساس سطح؛ کنارزدن موانع و پرتاب سفینه.
- **چراغ راهنمایی:** پاسخ به سبز و مهار پاسخ به قرمز.
- **بگرد و پیدا کن:** حفظ نمونه برای دو ثانیه، سپس یافتن تنها تطبیق دقیق میان اشیای مشابه؛ ده دور اصلی.
- **حواستو جمع کن:** تطبیق با یک، دو یا سه محرک قبل، بدون تطبیق‌های ناخواسته.
- **رنگ و کلمه / استروپ:** چهار قانون مستقل برای دایره، رنگ نوشته، معنای نوشته و هم‌زمان رنگ و معنا.

تنظیمات در `src/config.js` متمرکزند. در جلسات اصلی محرکی، ۱۵۰ نوبت امتیازدار و دقیقاً ۳۰ هدف وجود دارد. فاصلهٔ آغاز نوبت‌ها ۱۰۰۰ میلی‌ثانیه و زمان نمایش آسان/متوسط/سخت ۳۰۰/۲۰۰/۱۰۰ میلی‌ثانیه است. دکمهٔ ثابت یا کلید فاصله تا پایان پنجرهٔ یک‌ثانیه‌ای پاسخ را ثبت می‌کند. تکرار پاسخ در یک نوبت نادیده گرفته می‌شود.

استروپ چهار بلوک ۴۰، ۴۰، ۴۰ و ۳۰ نوبتی با ۸، ۸، ۸ و ۶ هدف دارد. پیش از هر تغییر قانون، زمان متوقف می‌شود و راهنمای مرحله نمایش داده می‌شود. در حافظهٔ فعال، یک تا سه محرک آغازین خارج از ۱۵۰ نوبت امتیازدار هستند.

در آموزش کشتی و سفینه، پنج وسیله یکی‌یکی نمایش داده می‌شوند: بازیکن وسیلهٔ لازم را انتخاب و وسیلهٔ غیرضروری را رد می‌کند. این آموزش بدون ذخیرهٔ امتیاز است. در بازی اصلی، گزینهٔ رد وجود ندارد و اشیای غیرضروری باید نادیده گرفته شوند. انتخاب اشتباه یک‌بار دو ثانیه از زمان کم می‌کند.

## امتیاز و ذخیره‌سازی

امتیاز بازی‌های محرکی تعداد هدف‌های درست منهای انتخاب‌های اشتباه، با حداقل صفر است. امتیاز جست‌وجو تعداد کشف‌های درست و امتیاز ماجراجویی تعداد وسایل ضروری جمع‌شده است. برای موفقیت در ماجراجویی، خروج با کشتی یا سفینه نیز باید قبل از پایان زمان انجام شود.

نتیجه، تعداد پاسخ درست، خطای حذف، انتخاب اشتباه، طولانی‌ترین زنجیرهٔ درست، زمان فعال و میانگین واکنش درست در `SessionResult` ثبت می‌شود. زمان واکنش فقط برای بازی‌های محرکی و جست‌وجو محاسبه می‌شود؛ بدون پاسخ درست، مقدار آن `null` است. امتیازهای سطح‌های متفاوت جدا هستند.

آخرین نتیجه و بهترین نتیجهٔ هر بازی/سطح به همراه ترجیح صدا در کلید `havaas:v1` در `localStorage` ذخیره می‌شود. آموزش ذخیره نمی‌شود. اگر ذخیره‌سازی مسدود باشد یا داده خراب شده باشد، بازی ادامه دارد. دادهٔ فردی جمع‌آوری نمی‌شود و اطلاعات به سرور ارسال نمی‌شود.

## ساختار و آزمون

`src/core/` موتور جلسه، ساعت فعال، تصادفی‌سازی و ذخیره‌سازی را نگه می‌دارد؛ `src/games/` قواعد مستقل هفت بازی را تعریف می‌کند. قراردادهای `GameConfig` و `SessionResult` در JSDoc تنظیمات مشخص هستند. رابط در `src/app.js` و تصویرسازی‌های برداری در `src/visuals.js` قرار دارند.

آزمون‌ها شامل پایان کامل آموزش و بازی اصلی هر هفت بازی در سه سطح، نسبت اهداف، قواعد حافظه و استروپ، مرز زمانی، توقف و ادامه، ورودی تکراری، موانع، جریمه‌ها، ذخیره‌سازی خراب و جریان صفحه‌ها با DOM شبیه‌سازی‌شده هستند.

در این محیط مرورگر قابل کنترل در دسترس نبود؛ آزمون بصری در عرض‌های ۳۶۰، ۷۶۸ و ۱۴۴۰ پیکسل، لمس روی دستگاه واقعی و پخش صوت باید در مرورگر واقعی نیز بررسی شوند. آزمون DOM جای آزمون چیدمان و زمان واقعی نمایش روی دستگاه را نمی‌گیرد.
