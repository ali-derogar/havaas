# محیط‌های تصویری حواس

شش محیط اصلی با ابزار داخلی `image_gen` ساخته شده‌اند. متن دقیق پرامپت هر تصویر در [prompts.json](prompts.json) نگهداری می‌شود.

- [shore-v1.png](shore-v1.png): ساحل آرام برای مأموریت کشتی.
- [space-v1.png](space-v1.png): پایگاه ماه برای مأموریت سفینه.
- [pond-v1.png](pond-v1.png): آبگیر برای شکار ماهی.
- [meadow-v1.png](meadow-v1.png): باغ برای شکار ستاره، پروانه و پرنده.
- [desk-v1.png](desk-v1.png): میز آرام برای جست‌وجو، حافظه و استروپ.
- [street-v1.png](street-v1.png): خیابان برای چراغ راهنمایی.

تصاویر عمداً در مرکز خلوت‌اند و وسیله، حیوان یا محرک هدف ندارند. وسایل و تمام محرک‌های امتیازدار همچنان با SVG دقیق رسم می‌شوند. کشتی و سفینه هم لایهٔ جدا دارند؛ پس‌زمینه بخشی از پاسخ‌های بازی نیست.

بارگیری و رمزگشایی پس‌زمینه پیش از شروع ساعت بازی انجام می‌شود. اگر تصویر در دسترس نباشد، محیط برداری محلی جایگزین می‌شود. در شکار سخت، پس‌زمینهٔ انتزاعی حفظ شده و برای خانوادهٔ اشکال از محیط کلاس استفاده می‌شود. فایل‌ها داخل پروژه و بستهٔ Docker هستند و سرویس تصویر خارجی هنگام بازی لازم نیست.

نسخهٔ ارائهٔ تازهٔ بازی‌ها `stimulusVersion=4` است و در تنظیمات زمان شروع ثبت می‌شود. دورهای جست‌وجوی جدید میان دورها برای آمادگی توقف دارند؛ `roundFlow=ready` آن‌ها را در مقایسهٔ پیشرفت از اجرای پیوستهٔ قدیمی جدا می‌کند.
