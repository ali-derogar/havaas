# تغییرات بازی‌ها و نسخهٔ انگلیسی

این نسخه چهار بند «درخواست تغییرات پروژه بازی ها.pdf» را پیاده می‌کند. نسخهٔ تجربه ۴ و نسخهٔ ارائهٔ محرک ۹ است. شمار نوبت‌ها، هدف‌ها، فرمول امتیاز و نسخه‌های پروتکل حفظ شده‌اند.

## بازی‌ها

- پروانه در نمونه، آموزش، میدان و مرور پاسخ‌ها افقی و رو به راست است. چرخش پایه داخل SVG قرار دارد و با خاموش‌شدن انیمیشن تزئینی حذف نمی‌شود.
- شکار در بخش‌های ۲۰، ۵۰ و ۸۰ نوبتی رنگ هدف را تغییر می‌دهد. در حالت دوهدفه، هر بخش دو رنگ متمایز دارد و شمار دو هدف در همان بخش برابر است. معرفی نمونهٔ تازه سه ثانیه طول می‌کشد و از زمان فعال جداست.
- استروپ چهار رنگ آبی، سبز، قرمز و زرد را با ترتیب بذرگذاری‌شده در چهار بخش استفاده می‌کند. قانون، تصویر راهنما، مرور پاسخ و صدای هر بخش با رنگ همان بخش هماهنگ‌اند. کلمات فارسی و انگلیسی با شناسهٔ رنگ مشترک ذخیره می‌شوند؛ زبان نمایش کلمه در خود محرک ثبت می‌شود.
- جست‌وجو در هر دور رنگ اصلی تازه‌ای دارد. در سطح سخت، شرط تمایز جزئیات و قواعد حالت دوهدفه حفظ می‌شوند.
- N-back رنگ یکنواختی برای اشکال هر جلسه دارد که میان جلسه‌ها تغییر می‌کند؛ مرجع حافظه همان رنگ را دارد. رنگ طبیعی اسباب‌بازی‌ها و وسایل مأموریت‌ها حفظ می‌شود.
- مسیر چراغ راهنمایی در مختصات بازی ۱٫۵ برابر شده و سه دست‌انداز دارد. پیشرفت در موتور محاسبه می‌شود. در دست‌انداز، ماشین باید یک نوبت توقف را بگذراند و برای ادامه به پاسخ تازه به سبز نیاز دارد. پاسخ به قرمز خطای معمول است و ماشین را حرکت نمی‌دهد. نوبت اضافی ایجاد نمی‌شود؛ بازی اصلی همچنان ۱۵۰ نوبت و ۳۰ هدف دارد. تمرین پنج‌نوبتی یک چرخهٔ حرکت، توقف و حرکت دوباره را نشان می‌دهد.

## انتخاب زبان

انتخاب فارسی/English در سربرگ صفحهٔ اول و صفحات سامانه وجود دارد. فارسی پیش‌فرض است و انتخاب در همین مرورگر ذخیره می‌شود. پارامتر `?lang=en` یا `?lang=fa` نیز برای بازکردن مستقیم صفحه، از جمله گزارش خانواده، پشتیبانی می‌شود.

رابط کاربر و مدیر، آموزش‌ها، گزارش‌ها، چاپ/PDF، پیام‌های خطا و صفحهٔ آفلاین ترجمه می‌شوند. ترجمه فقط به رشته‌های نوشته‌شده در کد اعمال می‌شود؛ نام، مشخصات، یادداشت، عنوان پروفایل سفارشی و سایر داده‌های کاربران دست‌نخورده می‌مانند. تغییر زبان فرم را دوباره بارگذاری نمی‌کند و مقادیر تایپ‌شده در حافظهٔ همان صفحه حفظ می‌شوند. هنگام بازی، انتخاب تازه پس از پایان یا خروج از جلسه اعمال می‌شود.

فارسی راست‌به‌چپ، با تاریخ شمسی و ارقام فارسی است؛ انگلیسی چپ‌به‌راست، با تاریخ میلادی و ارقام لاتین است. تاریخ تولد انگلیسی از ورودی استاندارد تاریخ استفاده می‌کند. ذخیره‌سازی تاریخ‌ها استاندارد باقی می‌ماند و نمایش زمان و مرز روز مرکز بر مبنای تهران است. جهت واقعی حرکت و کلیدهای جهت بازی با زبان عوض نمی‌شوند.

## API و سازگاری

- درخواست شروع جلسه، `locale: "fa" | "en"` می‌پذیرد؛ پیش‌فرض `fa` است و مقدار ناشناخته رد می‌شود.
- سرور `stimulusPlan.colorsByPhase` را با بذر مستقل از توالی پاسخ‌ها تولید و در تنظیمات جلسه ذخیره می‌کند. برنامهٔ رنگ ارسالی کلاینت مبنای شروع جلسه نیست.
- نتیجهٔ نسخهٔ ۴ شامل زبان و برنامهٔ رنگ است. نتیجهٔ چراغ، `trafficRouteVersion: 1` و وضعیت مسیر بازسازی‌شده را نیز دارد. سرور این اطلاعات را از تنظیمات و پاسخ‌های معتبر محاسبه می‌کند.
- نسخه‌های تجربهٔ ۱، ۲ و ۳ همچنان پذیرفته می‌شوند؛ شروع با این نسخه‌ها محرک نسخهٔ ۸ و رفتار قبلی را می‌گیرد. جلسهٔ قدیمی با تنظیمات ذخیره‌شدهٔ خودش اعتبارسنجی می‌شود.
- برای رفتار تازهٔ شکار، چراغ و استروپ، ارزیابی سازگار لازم است؛ ارزیابی‌ها و سوابق قدیمی حذف نمی‌شوند. ارزیابی استروپ و مقایسهٔ پیشرفت آن برای فارسی و انگلیسی جداست.
- سربرگ `X-App-Locale` زبان پیام‌های API، متن گزارش و خروجی CSV را تعیین می‌کند. زمینهٔ زبان هر درخواست مستقل است و میان درخواست‌های هم‌زمان نشت نمی‌کند.
- فیلدهای جدید در خلاصهٔ گزارش و خروجی JSON حفظ و هنگام انتقال داده اعتبارسنجی می‌شوند. تنظیمات و نتیجه در JSON موجود پایگاه ذخیره می‌شوند؛ مهاجرت ساختاری SQL لازم نیست.

## صدا و PWA

۳۱ فایل فارسی ضبط‌شده حفظ شده‌اند. ۲۲ راهنمای فارسی برای رنگ‌های متغیر و مسیر جدید اضافه شده است؛ مشخصات تولیدشان جدا از اطلاعات ضبط‌های اصلی در `assets/audio/scripts.json` ثبت شده است.

بستهٔ انگلیسی شامل ۵۳ فایل محلی در `assets/audio/en` است و با صدای `en-US-JennyNeural` تولید شده است. فایل مشخصات همان پوشه، متن، گوینده و تنظیمات تولید را نگه می‌دارد. اجرای بازی به سرویس تولید صدا یا اینترنت برای گویندگی وابسته نیست؛ ورود و ثبت نتیجه همچنان اتصال به سرور می‌خواهند.

ساخت بستهٔ انگلیسی:

```sh
EDGE_TTS_BIN=.local/voice-build/bin/edge-tts node scripts/generate-guidance.mjs --locale en
```

برای پیش‌نمایش و تولید جزئی از `--output` با پوشه‌ای مستقل استفاده کنید. تولید جزئی اجازهٔ جایگزینی بستهٔ زندهٔ فارسی یا انگلیسی را ندارد. تولید کامل فارسی با خروجی پیش‌فرض، ضبط‌های موجود را با صدای مصنوعی جایگزین می‌کند؛ برای بازسازی نمونهٔ فارسی هم خروجی مستقل تعیین کنید.

مانیفست انگلیسی و هر دو بستهٔ زبان و صوت وارد ساخت و کش PWA می‌شوند. شناسهٔ انتشار از محتوا محاسبه می‌شود؛ فایل‌های موقت تولید صدا وارد کش نمی‌شوند. رمزگشایی سالم و مطابقت متن با فایل، جای بازبینی شنیداری انسانی دربارهٔ لحن و تلفظ را نمی‌گیرد.

## بررسی

```sh
npm run check:i18n
npm test
npm run test:api
npm run test:e2e
npm run build
```

آزمون‌های متصل به پایگاه داده به `DATABASE_URL` آزمایشی نیاز دارند؛ هر مجموعه پایگاه موقت خودش را ایجاد و پاک می‌کند. برای اجرای همهٔ آزمون‌های واحد و API بدون پرش، `npm test` را با همان اتصال آزمایشی اجرا کنید.

آزمون‌های جدید، توالی رنگ‌ها و توازن هدف‌ها، زمان معرفی قانون، توقف و حرکت مجدد، بازسازی سرور، نسخه‌های قدیمی، نگهداری زبان در انتقال داده، ترجمه بدون تغییر دادهٔ کاربر، تکمیل واقعی بازی و گزارش انگلیسی را پوشش می‌دهند. بررسی پوشش ترجمه، قطعه‌های متن کد را با واژه‌نامهٔ انگلیسی تطبیق می‌دهد و محتوای کاربران را اسکن نمی‌کند.

بررسی تکمیلی درخواست PDF، معرفی، آمادگی و اجرای هر هفت بازی را در هر دو زبان با اندازه‌های `320×568`، `360×640`، `390×844`، `768×1024`، `1440×900` و `800×360` پوشش می‌دهد (`tests/browser/pdf-request.spec.mjs`). در حالت افقی، نوار ابزار در ستون پاسخ و متناسب با جهت زبان قرار می‌گیرد تا محرک را نپوشاند. متن‌های عدددار راهنمای حافظه و جست‌وجو به‌صورت جملهٔ کامل ترجمه می‌شوند؛ فاصلهٔ دقیق محرک مرجع در راهنما، پاسخ و مرور انگلیسی حفظ می‌شود. آزمون‌های فشرده نیز خوانایی کنترل‌ها را در پوسته‌های روشن و تیره بررسی می‌کنند.

بازبینی دوم، اندازه‌های افقی `480×320`، `568×320`، `640×360`، `667×375`، `736×414` و `1024×520`، هر دو حالت چراغ و هر سه نوع محرک حافظه را نیز پوشش می‌دهد. پیام تغییر رنگ و شمارش معکوس در صفحهٔ کوتاه کامل دیده می‌شوند و دکمهٔ توقف بالای لایهٔ کنترل‌ها قرار می‌گیرد. در میدان فشردهٔ شکار، جابه‌جایی عمودی داخل ردیف هر حشره محدود می‌شود تا ناحیه‌های لمس روی هم نیفتند؛ مسیر افقی، زمان نمایش و داده‌های امتیازدهی حفظ می‌شوند. مرور خطاهای شکار نیز نمونهٔ هدف همان بخش را نشان می‌دهد، نه رنگ هدف بخش آخر.
