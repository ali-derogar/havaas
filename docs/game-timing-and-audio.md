# زمان‌بندی بازی و پخش راهنما

نسخهٔ تجربهٔ ۳، زمان‌بندی هر حالت و سطح را قابل تنظیم می‌کند. نسخهٔ پروتکل بازی‌ها و تعداد نوبت‌ها، هدف‌ها، وسایل و موانع تغییر نکرده‌اند.

## پنل و اولویت تنظیمات

تنظیمات عمومی در صفحهٔ تنظیمات ادمین قرار دارند. تنظیم اختصاصی در تب «تنظیمات تمرین» همان کاربر است. برای هر بازی، حالت و سطح یک مجموعهٔ کامل زمان ذخیره می‌شود؛ شکار گروه‌های ثابت و متحرک جدا دارد. ماهی، پرنده و پروانه از گروه متحرک استفاده می‌کنند.

اولویت: اختصاصی کاربر، عمومی و سپس پیش‌فرض فعلی بازی. دکمهٔ «استفاده از تنظیم عمومی» مقدار اختصاصی را کنار می‌گذارد؛ بازگردانی عمومی، پیش‌فرض داخلی را فعال می‌کند. فرم‌ها مقادیر مؤثر و منبعشان را نشان می‌دهند. تعارض ویرایش، پیش‌نویس را حفظ می‌کند؛ دریافت آخرین تنظیمات پس از کنارگذاشتن پیش‌نویس ممکن است.

ورودی پنل ثانیه و ذخیره‌سازی میلی‌ثانیه است؛ گام همهٔ ورودی‌ها ۵۰ میلی‌ثانیه است:

- واکنشی: `visibleMs` از ۱۰۰ تا ۱۰۰۰۰ و `intervalMs` از ۲۰۰ تا ۱۵۰۰۰؛ فاصلهٔ آغاز نوبت‌ها نباید کمتر از مدت نمایش باشد. پاسخ از آغاز نمایش تا نوبت بعد مجاز است.
- جست‌وجو: `previewMs` از ۱۰۰ تا ۳۰۰۰۰ و `searchMs` از ۱۰۰۰ تا ۳۰۰۰۰۰.
- مأموریت: `limitMs` از ۵۰۰۰ تا ۶۰۰۰۰۰.

ارزیابی اولیه زمان‌های پیش‌فرض سطح آسان را نگه می‌دارد. تمرین آزاد زمان‌های مؤثر را هنگام شروع دریافت می‌کند؛ تکرار تمرین همان snapshot جلسهٔ قبلی را استفاده می‌کند. آموزش مأموریت‌ها همچنان بدون محدودیت زمانی است. شمارش شروع، اعلان سه‌ثانیه‌ای قانون و جریمهٔ انتخاب اشتباه قابل تنظیم نشده‌اند.

## رابط سرور و ذخیره‌سازی

- `GET/PATCH /api/admin/game-timings`: فقط ادمین؛ تنظیمات عمومی.
- `GET/PATCH /api/children/:id/game-timings`: خواندن مقدار مؤثر برای صاحب حساب و ادمین، نوشتن فقط ادمین.
- کلید: `gameId`، `variant`، `timingFamily`، `level` و `protocolVersion`. خانواده برای شکار `static` یا `moving` و برای بقیه `standard` است. نسخهٔ پروتکل در صورت ارسال باید با بازی یکسان باشد.
- درخواست PATCH شامل `timing` و `expectedRevision` است. `timing: null` بازگردانی را انجام می‌دهد. نبود رکورد، بازبینی صفر دارد؛ بازگردانی رکورد را با بازبینی تازه نگه می‌دارد تا فرم قدیمی قابل بازنویسی نباشد.
- مقادیر نامعتبر با ۴۰۰، نسخهٔ فرم مفقود با ۴۲۸ و تعارض با ۴۰۹ رد می‌شوند. ذخیرهٔ بدون تغییر بازبینی و تاریخچهٔ تازه نمی‌سازد.

مهاجرت ۰۰۵ جدول‌های `game_timing_defaults` و `child_game_timing_overrides` را اضافه می‌کند. تغییرات همراه انجام‌دهنده، بازی، حالت و سطح در تاریخچه ثبت می‌شوند. اعمال زمان‌بندی وابسته به انتخاب سطح ثابت یا تطبیقی نیست.

شروع جلسه زمان‌ها را از سرور انتخاب می‌کند؛ مقادیر ارسالی کلاینت جایگزین سیاست ادمین نمی‌شوند. `settings.timing` و `timingKey` در شروع ثبت می‌شوند. اعتبارسنجی نتیجه از همان snapshot استفاده می‌کند و دادهٔ زمان‌بندی داخل نتیجهٔ ارسالی را نادیده می‌گیرد. نتیجه، گزارش عمومی و خروجی JSON مقادیر واقعی را حفظ می‌کنند؛ گروه مقایسه بر پایهٔ زمان‌های مؤثر است، نه بازبینی رکورد تنظیمات.

کلاینت‌های تجربهٔ ۱ و ۲ زمان‌های قبلی را دریافت می‌کنند. نسخهٔ ناشناخته پیش از ایجاد جلسه رد می‌شود. بازی‌های قدیمیِ در حال اجرا بدون تغییر قابل تکمیل‌اند. ساخت PWA نسخهٔ کش تازه تولید می‌کند و رفتار فعلی به‌روزرسانی امن هنگام بازی حفظ شده است.

## صدا

هر ورود به بازی فقط یک تلاش خودکار دارد. آموزش، تغییر حالت یا سطح، مرور، نتیجه و تکرار همان بازی آن را تمدید نمی‌کنند. خروج از مسیر بازی و ورود دوباره یا رفتن به بازی دیگر یک فرصت تازه ایجاد می‌کند. خاموش‌بودن صدا و منع autoplay، تلاش‌های تکراری ایجاد نمی‌کنند.

دکمهٔ راهنما فایل متناسب با مرحله را از ابتدا پخش می‌کند. هنگام بازی یا شمارش زمان‌دار، ابتدا زمان متوقف و پنجرهٔ توقف باز می‌شود؛ ادامهٔ بازی صدا را قطع می‌کند. زمان مرور و آموزش از پیش متوقف است و نیاز به توقف اضافی ندارد. صداهای کوتاه بازخورد بازی حفظ شده‌اند.

## بررسی

آزمون‌های جدید در `tests/game-timing.test.mjs`، `tests/game-timing-api.test.mjs` و `tests/browser/game-timing.spec.mjs` مرز زمان‌ها، هر هفت موتور، تقدم سیاست‌ها، مجوز، تعارض هم‌زمان، snapshot، نسخه‌های قدیمی، گزارش، انتقال سوابق و رفتار صدا را پوشش می‌دهند. آزمون‌های API و مرورگر از پایگاه‌های دادهٔ موقت استفاده می‌کنند.

```sh
node --env-file=.env --test tests/*.test.mjs
node --env-file=.env node_modules/@playwright/test/cli.js test tests/browser/game-timing.spec.mjs tests/browser/play-lifecycle.spec.mjs tests/browser/compact-play.spec.mjs tests/browser/management-panels.spec.mjs tests/browser/review-updates.spec.mjs
npm run build
```
